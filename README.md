# 📱 Rajeali App

## 🧠 فكرة التطبيق

**Rajeali (رجعلي)** هو تطبيق ذكي يساعد المستخدمين على استرجاع أغراضهم المفقودة بسهولة.

يعتمد التطبيق على فكرة بسيطة:

* إذا ضاع منك غرض ➜ بتنزل إعلان عنه داخل التطبيق
* إذا شخص لقى غرض ➜ برضو بنزله
* النظام باستخدام الذكاء الاصطناعي (AI) يعمل **مطابقة ذكية** بين الحالات
* عند وجود تطابق ➜ يتم فتح **محادثة مباشرة** بين الطرفين

---

## 🚀 المميزات

* 🔍 إضافة غرض مفقود أو موجود
* 🤖 مطابقة ذكية باستخدام AI
* 💬 محادثة مباشرة بين المستخدمين
* 📍 إمكانية التوسع لإضافة الموقع الجغرافي
* 🔐 نظام تسجيل دخول (قابل للتطوير)

---

## 🛠️ التقنيات المستخدمة

* Android , IOS (Dart / Flutter(Framwork))
* API Integration
* Firebase (ممكن استخدامه للمصادقة والدردشة)
* AI Matching Logic (قابل للتطوير)
